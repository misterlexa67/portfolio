# доставка.есть — исходники

Демо-концепт маркетплейса доставки еды по Нижнему Новгороду. Сервис вымышленный.

```
npm install
npm run dev      # разработка, http://localhost:5173
npm test         # тесты бизнес-правил (Vitest)
npm run build    # сборка в ../ (delivery/index.html + delivery/static)
```

## Структура

- `src/api/` — сервисный слой, единственный источник правды: цены, итоги, баланс, статусы заказа.
  Асинхронные вызовы с задержкой, данные в localStorage. Чтобы подключить настоящий бэкенд,
  достаточно заменить модули на HTTP-клиент с теми же сигнатурами — UI не меняется.
  - `pricing.ts` — расчёт денег (общий для корзины и оформления), зоны, промокоды
  - `orders.ts` — оформление (7 шагов, идемпотентность), отмена, оценка, чаевые, повтор
  - `tracking.ts` — ускоренная симуляция статусов и позиции курьера
  - `admin.ts` — API владельца (демо-PIN 0000)
- `src/components/` — общие компоненты (шторки, карта, карточки, корзина)
- `src/screens/` — экраны клиента
- `src/admin/` — панель владельца (`#/admin`, также `/delivery/admin/`)
- `src/tokens/` — дизайн-токены
- `tests/` — тесты сервисного слоя

Изображения: `../assets/cut/` (нарезка спрайтов скриптами из `../tools/`).
